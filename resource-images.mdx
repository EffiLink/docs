## Overview

Image resources used for email tasks.

`POST /v5/campaign/mail/uploadImageToGallery`

---

## Request Parameters

<ParamField body="fileData" type="string" required>
  Base64 encoded binary image data. The size is no more than 2M and supports formats such as jpeg, jpg, png, bmp, and gif.
</ParamField>

---

## Response

<ResponseField name="code" type="int">
  HTTP-style status code. `200` on success.
</ResponseField>

<ResponseField name="message" type="string">
  A human-readable status message. `null` or empty string on success.
</ResponseField>

<ResponseField name="url" type="string">
  The access URL of this image on the public network.
</ResponseField>

---

curl --request POST \

  --header 'Content-Type: application/json' \
