# [如何发送营销类邮件](https://developers.effilink.co/api-reference/v5/how-to-send-campaign-emails.html#%E5%A6%82%E4%BD%95%E5%8F%91%E9%80%81%E8%90%A5%E9%94%80%E7%B1%BB%E9%82%AE%E4%BB%B6)

更新时间：2023-06-03 09:00

设置帐户并完成身份认证后，就可以开始使用 EffiLink 营销类邮件API 发送批量邮件。

常用的使用流程是：先[导入联系人](https://developers.effilink.co/api-reference/v5/contacts.html)数据到指定的联系组，再向指定的联系组[发送](https://developers.effilink.co/api-reference/v5/sends.html)指定的模板内容。
