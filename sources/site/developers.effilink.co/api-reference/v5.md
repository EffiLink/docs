# 概览

更新时间：2023-06-03 09:00

本指南将为您提供使用EffiLink API去 管理用户、电子邮件活动、发送短信、自动化工作流程等所需的一切，旨在帮助您快速轻松地创建功能性应用程序或集成。

我们的 API正在持续过渡和升级中，如果您是首次或者新增业务调用API，请使用最新版本EffiLink API V5.0。

# [快速入门](https://developers.effilink.co/api-reference/v5/#%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8)

使用 REST API，您可以以编程方式执行各种代码操作，这些操作也可通过用户界面执行。本指南包含一个快速入门部分，其中包含有关 API 的重要概念、身份验证说明。

### [获取 API Key进行身份验证](https://developers.effilink.co/api-reference/v5/#%E8%8E%B7%E5%8F%96-api-key%E8%BF%9B%E8%A1%8C%E8%BA%AB%E4%BB%BD%E9%AA%8C%E8%AF%81)

您需要一个EffiLink 帐户，可以从我们的[注册页面](https://www.effilink.co/register)免费创建一个。 确认帐户后，请从设置->接口与推送->[API Keys](https://app.effilink.co/setting/apikey/) 中获取 API 密钥。

### [使用EffiLink API 可以做什么？](https://developers.effilink.co/api-reference/v5/#%E4%BD%BF%E7%94%A8effilink-api-%E5%8F%AF%E4%BB%A5%E5%81%9A%E4%BB%80%E4%B9%88)

#### [1\. 发送事务邮件：](https://developers.effilink.co/api-reference/v5/#_1-%E5%8F%91%E9%80%81%E4%BA%8B%E5%8A%A1%E9%82%AE%E4%BB%B6)

创建和发送“触发式”电子邮件，例如订单确认、密码重置和确认电子邮件。[事务邮件API](https://developers.effilink.co/api-reference/v5/how-to-send-transactional-emails.html)

#### [2\. 发送营销邮件](https://developers.effilink.co/api-reference/v5/#_2-%E5%8F%91%E9%80%81%E8%90%A5%E9%94%80%E9%82%AE%E4%BB%B6)

创建并发送设计精美的营销活动，例如新闻通讯和发布公告邮件。[营销邮件API](https://developers.effilink.co/api-reference/v5/sends.html)

#### [3\. 发送短消息](https://developers.effilink.co/api-reference/v5/#_3-%E5%8F%91%E9%80%81%E7%9F%AD%E6%B6%88%E6%81%AF)

发送事务短信，例如通知您的客户有关货运状态或告知他们确认码。

创建营销短信活动，将公告或促销优惠以短信形式发送给您的客户。[短信API](https://developers.effilink.co/api-reference/v5/sms-send.html)

#### [4\. 管理联系人](https://developers.effilink.co/api-reference/v5/#_4-%E7%AE%A1%E7%90%86%E8%81%94%E7%B3%BB%E4%BA%BA)

管理联系人以及如何将联系人导入和导出到 EffiLink 帐户。

获取特定联系人的营销活动统计数据。 [联系人API](https://developers.effilink.co/api-reference/v5/contacts.html)
