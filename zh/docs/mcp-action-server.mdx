EffiLink 在 `https://api.effilink.co/mcp` 提供一个托管的远程 [Model Context Protocol](https://modelcontextprotocol.io)（MCP）服务。AI 客户端或智能体使用你的 API 密钥连接后，就可以代表你发送事务性邮件，而无需你手动编写每个 API 请求。

<Warning>
  该服务会对你的账户执行**真实且经过身份验证的操作**，包括发送真实邮件并消耗你的额度。请仅将它连接到你信任的客户端和智能体，并像对待任何后端服务中的密钥一样妥善保管你的 API 密钥。
</Warning>

## 快速参考

|  |  |
| --- | --- |
| **服务地址** | `https://api.effilink.co/mcp` |
| **传输方式** | HTTP（远程服务，无需安装或自行托管） |
| **身份验证** | 在 `ApiKey` 请求头中携带你的 EffiLink API 密钥 |
| **功能范围** | 事务性邮件 API |
| **沙盒模式** | 支持 |
| **只读文档检索** | 请使用 [MCP 检索服务](/zh/docs/mcp-server) |

## 开始之前

<Steps>
  <Step title="获取 API 密钥">
    在你的 EffiLink 账户设置中创建 API 密钥。详情请参阅 [API 密钥](/zh/docs/api-keys)。
  </Step>
  <Step title="配置发件人">
    发送邮件之前，请先设置发件域名和发件人。设置方法请参阅[发件人配置](/zh/api/senders)。
  </Step>
</Steps>

## 连接客户端

该服务使用 `ApiKey` 请求头对每个连接进行身份验证，与 REST API 使用的请求头相同。你的客户端必须能够在连接时发送自定义请求头。

<Tabs>
  <Tab title="Claude Code">
    在终端中运行以下命令：

    ```bash
    claude mcp add --transport http effilink https://api.effilink.co/mcp \
      --header "ApiKey: your_api_key_here"
    ```
  </Tab>
  <Tab title="Cursor">
    将该服务添加到你的 MCP 配置中（通常位于 `~/.cursor/mcp.json`，或通过 **设置 → MCP** 添加）：

    ```json
    {
      "mcpServers": {
        "effilink": {
          "url": "https://api.effilink.co/mcp",
          "headers": {
            "ApiKey": "your_api_key_here"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab title="其他 MCP 客户端">
    任何支持远程 HTTP MCP 服务**并且允许设置自定义请求头**的客户端都可以连接。使用上方的服务地址，并添加请求头 `ApiKey: your_api_key_here`。无法发送自定义请求头的客户端（例如部分网页版连接器界面）无法使用 API 密钥连接。
  </Tab>
</Tabs>

<Tip>
  请将 `your_api_key_here` 替换为你自己的密钥。避免将包含密钥的配置文件提交到代码仓库。
</Tip>

## 它能做什么

该服务目前提供一个工具：

- **发送事务性邮件。** 通过[事务性邮件 API](/zh/api/transactional-send) 向收件人发送邮件。可用字段请参见[事务邮件](/zh/docs/transactional-email)。

连接后，客户端会从服务读取可用工具列表，因此总能看到当前的工具名称和输入结构。

<Info>
  后续会陆续增加更多工具，本页面也会随之更新。
</Info>

该工具遵循与对应 REST API 端点相同的规则，因此 API 参考中的请求字段、限制和错误代码同样适用。

## 示例提问

连接后，你可以向 AI 客户端提出类似这样的请求：

- "向 [jane@example.com](mailto:jane@example.com) 发送一封使用我们重置模板的密码重置邮件。"
- "以沙盒模式向 [order-123@example.com](mailto:order-123@example.com) 发送一封订单确认邮件。"
- "给我们的新用户发送一封欢迎邮件，并展示你使用的请求。"

## 安全与测试

- **会发送真实邮件。** 除非请求使用沙盒模式，否则该服务会实际发送邮件并消耗你的额度。
- **先测试。** 该服务支持沙盒模式，它会校验请求但不发送任何内容。参见[沙盒模式](/zh/docs/sandbox-mode)，并让你的智能体在首次试用时使用它。
- **控制智能体的权限。** 许多客户端允许你逐次批准工具调用。在你信任该流程之前，请保持开启。
- **轮换泄露的密钥。** 如果你的 API 密钥已泄露，请在账户设置中更换，并更新客户端配置。

## 限制

- **目前仅支持发送。** 批量发送、投递报告、营销活动、短信、联系人、发件人和 Webhook 设置暂无法通过该服务使用。这些功能请使用 [REST API](/zh/api/transactional-send)。
- **需要已验证的发件人。** `senderMail` 必须已在你的账户中注册并通过验证，否则请求会被拒绝。
- **与 API 相同的限制。** 该服务遵循 EffiLink 自身的速率限制和额度规则。参见[速率限制](/zh/docs/rate-limits)。
