## API 端点

EffiLink 提供地理分布式的 API 端点，以确保高可用性和最佳访问性能。为了获得最佳延迟和可靠性，我们建议选择地理位置上离您的用户或应用服务器最近的端点：

- 中国大陆：
  ```text
  https://api.effilink.co
  ```
- 中国香港：
  ```text
  https://hk-api.effilink.co
  ```
- 欧盟地区：
  ```text
  https://eu-api.effilink.co
  ```

每个请求必须：

- 使用 **HTTPS** 发送
- 使用 `Content-Type: application/json`
- 包含身份验证头（`ApiKey` 或 `OAuth`）

<Note>
  参数名区分**大小写**。所有请求和响应数据都使用 UTF-8 编码。
</Note>

## HTTP 响应代码

| 代码 | 状态 | 含义 |
| --- | --- | --- |
| 200 | OK | 请求成功 |
| 400 | Bad Request | 数据格式无效或缺少必需参数 |
| 404 | Not Found | 接口不存在 |
| 405 | Method Not Allowed | 请按规定使用 GET 或 POST |
| 429 | Too Many Requests | 超过频率限制 |

## 分页

列表和搜索接口返回分页结果。使用以下查询参数来导航页面：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `pageSize` | integer | 每页记录数 |
| `pageIndex` | integer | 页码，从 `1` 开始 |
