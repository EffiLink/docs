EffiLink 短信 API 让你可以将时效性文本消息直接发送到用户的手机。常见用例包括用于两因素身份验证的一次性验证码（OTP）、订单和发货通知、预约提醒以及服务告警。单次 API 调用可以针对一个收件人，也可同时针对一个号码列表。

<Note>
  **监管要求：** 由于运营商合规规则的要求，所有短信内容和发件签名（如 `[EffiLink]`）必须预先在 EffiLink 平台上注册，并提交给运营商审核后方可发送。尝试发送未注册内容将被拒绝。请在发起 API 调用之前，先在 EffiLink 仪表盘中注册你的模板和签名。
</Note>

## 发送短信

**端点：** `POST /v5/sms/sends`

### cURL 示例

```bash
curl --request POST \
  --url https://api.effilink.co/v5/sms/sends \
  --header 'ApiKey: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "content": "[EffiLink] 您的验证码是 123456。",
    "toList": [
      {"mobile": "18800006666"},
      {"mobile": "18800008888"}
    ]
  }'
```

### 请求参数

| 参数 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| `content` | string | ✅ 是 | 完整的短信正文，含已登记的发件签名（例如 `[EffiLink]`）。必须与预审通过的模板格式匹配。 |
| `toList` | array[object] | ✅ 是 | 收件人对象列表。每个对象必须包含 `mobile` 字段，表示目标手机号。单次请求个性化发送最多 100 个收件人；如需按收件人覆盖内容，请参见[批量短信](/zh/docs/sms-batch)。 |
| `toList[].mobile` | string | ✅ 是 | 收件人的手机号（例如 `"18800006666"`）。 |
| `sandboxMode` | boolean | ❌ 否 | 设为 `true` 时执行测试发送。API 正常处理请求，但**不会**投递消息。适合开发阶段校验载荷。 |

### 响应

请求成功时返回 HTTP `200`，响应体如下：

```json
{
  "code": 200,
  "message": ""
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | integer | `200` 表示请求已被接受用于投递。 |
| `message` | string | 附加状态信息。成功时为空字符串。 |

## 沙箱模式

在请求体中传入 `"sandboxMode": true` 以在不发送真实消息的情况下测试集成。API 会校验载荷并返回正常的 `200` 响应，但不会向运营商投递短信。准备上线时请移除该字段或将其设为 `false`。
