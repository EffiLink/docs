配额定义了您在 EffiLink 账户中可创建或存储的对象最大数量。与[速率限制](/zh/docs/rate-limits)（约束 API 调用速度）不同，配额是账户内数据与活动的累积上限。配额按活跃账户执行，试用与付费方案下不同。

## 营销活动配额

您可创建的邮件和短信营销活动数量受账户类型限制。

| 活动类型 | 试用账户 | 付费账户 |
| --- | :-: | :-: |
| 邮件营销活动 | 100 | 不限制 |
| 短信营销活动 | 100 | 不限制 |

## 媒体库存储

上传到 EffiLink 媒体库的资源（图片、附件等）计入存储配额。

| 账户类型 | 存储上限 |
| :-: | :-: |
| 试用账户 | 10 MB |
| 付费账户 | 2 GB |

## 自动化工作流上限

每个账户可同时运行的活跃自动化工作流数量存在上限。

| 账户类型 | 活跃工作流 |
| :-: | :-: |
| 试用账户 | 0 |
| 付费账户 | 按购买数量 |

<Note>
  只有 **活跃** 工作流计入此配额。已暂停或已归档的工作流不占用名额，因此可以停用未使用的自动化以释放容量。
</Note>

## 联系人管理上限

以下与联系人相关的配额对所有账户类型一视同仁，与方案无关。

| 资源 | 上限 |
| --- | :-: |
| 自定义联系人属性 | 200 |
| 联系人分组（列表） | 300 |

## 发送量配额

发送量配额约束您可发送的消息总量。付费账户按需扩展，随方案和使用量增长。

| 消息类型 | 试用账户 | 付费账户 |
| --- | :-: | :-: |
| 邮件发送 | 100 | 按需 |
| 短信发送 | 0 | 按需 |

<Note>
  试用账户无法发送短信。升级到付费方案后可启用短信发送。
</Note>

## 达到配额时的处理

达到配额时，API 将拒绝创建新对象，直到您释放容量或升级账户。

**释放容量的方法：**

- **删除无用的营销活动**：移除不再需要的草稿或已完成活动。
- **清理媒体库**：删除已不被活跃活动引用的图片或文件。
- **停用闲置工作流**：暂停未在使用的自动化以释放活跃名额。
- **移除过时的联系人或分组**：删除不再活跃的联系人分组，控制在 300 个列表的上限内。

**提升上限的方法：** 联系 [EffiLink 客服](mailto:support@effilink.com) 或访问账户账单页，将试用升级为付费方案，或就大规模发送场景讨论更高级别的上限。
