sidebarTitle: "快速开始"
description: "本指南将引导您完成创建 EffiLink 账户、获取 API 密钥、设置已验证的发件人，并进行第一次 API 调用发送事务性邮件。整个过程不到 5 分钟。"
---

<Steps>
  <Step title="创建账户">
    在 [app.effilink.co](https://app.effilink.co) 注册。账户可免费创建，试用无需信用卡。
  </Step>
  <Step title="获取 API 密钥">
    1. 登录您的 EffiLink 账户。
    2. 点击右上角的 **设置**。
    3. 进入 **接口配置 → API  Keys**。
    4. 点击右上角的 **创建 API Key**。
    5. **立即保存生成的密钥**：密钥的后半部分仅显示一次。

    <Warning>
      请将 API 密钥保存在安全的密钥管理工具中。切勿提交到版本控制或暴露在客户端代码中。
    </Warning>
  </Step>
  <Step title="添加已验证的发件人">
    在发送邮件之前，您必须先[登记发送地址或域名](https://www.effilink.co/zh/resources/show/4071)：

    1. 进入 **设置 →发送配置→发件人&域名**。
    2. 添加您的发送邮箱地址（例如 `noreply@yourdomain.com`）。
    3. 通过添加 EffiLink 提供的 DNS 记录（SPF、DKIM、DMARC）完成域名验证。

    <Info>
      在域名验证进行期间，您可以使用沙箱模式进行测试。请参阅[沙箱模式](/zh/docs/sandbox-mode)。
    </Info>
  </Step>
  <Step title="发送第一封邮件">
    准备好 API 密钥和已验证的发件人后，发起以下 API 调用：

    ```bash
    curl --request POST \
      --url https://api.effilink.co/v5/transactional/mail/sends_customised \
      --header 'Content-Type: application/json' \
      --header 'ApiKey: YOUR_API_KEY' \
      --data '{
        "subject": "欢迎加入我们的平台",
        "content": "<p>您好！感谢注册。</p>",
        "senderMail": "noreply@yourdomain.com",
        "senderName": "您的公司",
        "to": {
          "email": "recipient@example.com",
          "name": "收件人姓名"
        }
      }'
    ```

    成功的响应示例：

    ```json
    {
      "code": 200,
      "message": ""
    }
    ```
  </Step>
</Steps>
